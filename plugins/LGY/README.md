# Liquid Glass YOUBAR

Turns Discord's YouBar into liquid glass: a translucent, tinted bar with a thin light border, a soft top highlight and a soft shadow. Works on Android and iOS, in dark and light themes.

- **Intensity**: Frosted, Balanced or Clear (how see-through the bar is).
- **Light border**: turn the thin edge on or off.
- **Native blur** (experimental, off by default): uses Discord's own blur view behind the bar when it can be found.
- **Preview** in the settings page.

It restyles the existing YouBar in place, so tab navigation, badges, the Music Controls player above it and other YouBar plugins keep working. Restart Discord after installing or enabling it.
